Use when service latency coincides with elevated DNS query latency.

Read-only diagnostic steps:
1. Show resolver query latency and query rate for each DNS server.
2. Check resolver CPU and cache hit ratio.
3. Identify clients with abnormal query rates (retry storms).
4. Verify upstream forwarder reachability and latency.
5. Escalate to network on-call if a resolver is saturated.
