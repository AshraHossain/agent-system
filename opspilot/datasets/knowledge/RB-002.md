Use when a fabric link shows packet loss together with rising CRC/FCS input
errors. This pattern indicates a physical-layer problem (optic, cable, dirty
connector) rather than congestion.

Read-only diagnostic steps:
1. Show CRC/FCS and input error counters on both ends of the link.
2. Check optic digital diagnostics (DOM): rx/tx power, temperature, bias.
3. Compare interface loss with active probe loss on the same path.
4. Confirm utilization is normal to rule out congestion.
5. Escalate to network on-call for a change-approved optic or cable replacement.
Do not reboot devices or clear counters during the investigation.
