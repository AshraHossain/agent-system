Use when ingress services show latency together with high CPU or session
table utilization on fw-1 or lb-1.

Read-only diagnostic steps:
1. Show CPU, memory and session table utilization.
2. Review new-connection rate and top source prefixes.
3. Check for policy-hit anomalies or connection floods.
4. Correlate with ingress service latency.
5. Escalate to network on-call and security if traffic looks abusive.
