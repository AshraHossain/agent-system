Use when an uplink shows sustained utilization above 85% together with rising
latency or tail drops (output discards). Congestion loss is usually not
accompanied by CRC/FCS errors.

Read-only diagnostic steps:
1. Show interface utilization and output discard counters on both link ends.
2. Review QoS queue drop counters for the congested egress queue.
3. Identify top talkers on the link using flow telemetry for the window.
4. Compare ECMP load distribution against the sibling uplink.
5. Escalate to network on-call to request an approved traffic-engineering change.
